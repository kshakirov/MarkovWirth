В рамках заложения фундамента вычислительного ядра `MarkovWirth` необходимо реализовать первые изолированные функциональные прототипы двух ключевых компонентов системы:
1. **Кассетный автомат Вирта** (`bin/parse_csv_byte.js`) — для побайтового сканирования входного потока и сборки CSV-матрицы.
2. **Марковский оракул подстановок** (`lib/parser/markov/parse_escaped_byte.js`) — для локальной обработки экранированных полей согласно стандарту RFC 4180.

Эта задача носит исследовательский характер (Proof of Concept) и призвана подтвердить математическую гипотезу о возможности локализации Нормальных Алгоритмов Маркова (НАМ) внутри регулярного потока.

## Требования и Инварианты (v0.1.0)
* **Побайтовый спуск:** Реализация базового рекурсивного обхода файла без использования высокоуровневых строковых методов V8.
* **Базовый НАМ:** Создание упорядоченного массива правил `rules` для схлопывания экранированных кавычек (`""` -> `"`) и поиска разделителей (`",`).
* **Изолированное тестирование:** Написание первичного скрипта валидации (`lib/parser/markov/test_parser.js`) для подтверждения прохождения базовых тест-кейсов.

## Реализация и коммиты
*Данный тикет закрывается ретроспективно на основе уже созданной базовой структуры файлов в ветке `dev`.*
